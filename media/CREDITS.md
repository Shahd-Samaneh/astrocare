# Media credits

All media in this folder was **generated by the team with `scripts/make_relax_media.py`**
(numpy + Python standard library). Nothing was downloaded, so there are no third-party
authors or licences to credit.

| File | What it is |
|---|---|
| `scenes/earthrise.png` | Aurora curtains over Earth's night-side limb (procedural) |
| `scenes/ocean-shore.png` | Calm sea at dusk, low sun, shoreline (procedural) |
| `scenes/forest-stream.png` | Mountains and pine forest at dusk with a stream (procedural) |
| `audio/ocean-shore-nature.wav` | Waves: filtered noise with slow swells, 75 s loop |
| `audio/rain-window-nature.wav` | Soft rain: filtered noise with scattered drops, 75 s loop |
| `audio/forest-stream-nature.wav` | Wind in the trees: brown noise with slow gusts, 75 s loop |
| `audio/music-ambient-pad.wav` | Slow ambient chord pad (Am–F–G–Em), 75 s loop |

To regenerate: `python scripts/make_relax_media.py` (deterministic, overwrites the files above).
